authoritative detailed record of **Phases 1–47**. The README keeps a concise
current-state summary for first-time visitors; version-level changes and

dependency-ordered roadmap lives in [architecture.md](architecture.md) §6.

| 47C (model-comparison slice) | Two-candidate comparison with a CONDITIONAL AICc. M0 is the existing mono-exponential fit reused verbatim; M1 adds an additive baseline `B + A·exp(−k·(t − t_ref))` with `A, B, k ≥ 0`, fitted by exact constrained least squares at each trial rate (the two-variable non-negative problem has three faces, both single-coefficient faces are always feasible for non-negative data, so enumerating them is exact, deterministic and cannot return a negative coefficient; the 2×2 determinant is guarded because it vanishes as `q → 0`, and the published objective is recomputed from residuals). It is unavailable with structured reasons when the assumption is absent, the fit failed, SSE is non-finite or zero, or `n − K − 1 ≤ 0`; zero SSE is never replaced by an epsilon and ordinary AIC is never substituted. The difference is shown as arithmetic only, with no threshold, weight or verdict.
